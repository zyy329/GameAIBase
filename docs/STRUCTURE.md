# docs/ 目录说明

## 用途
存放项目所有的文档与资料

## 核心子目录
- `design/`: 游戏策划设计文档
- `architecture/`: 主架构文档与 ADR
- `patterns/`: 架构模式与反面示例
- `templates/`: 文档模板(来源 CCGS 精简)
- `process/`: 开发流程(七阶段管线, 入口 WORKFLOW.md)
- `engine-reference/godot/`: Godot 版本参考(AI 建议 API 前必查)
- `production/`: 规划与追踪产物(epics, sprints, milestones, playtests)
